# Karin Travel: website handoff kit

1. Unzip this folder into an empty project folder (for example `C:\Users\you\WebstormProjects\karin-travel`).
2. Open a terminal in that folder and start Claude Code there.
3. Paste the text from `START_PROMPT.txt` as your first message.

To preview the approved design yourself, double-click `design/dusk-reference.html`. Keep the `assets` folder next to `design` so the photos load.
